# БЕТОН — архитектура вне времени

Русскоязычный концепт архитектурного журнала в стиле брутализм.

## Как открыть

1. Нажмите **Code → Download ZIP** и распакуйте архив.
2. Откройте **beton.html** двойным щелчком в браузере. CSS и JavaScript уже встроены в этот файл.

Для фотографий с Unsplash и шрифтов Google Fonts нужен интернет. Фотографии служат иллюстрациями эстетики, а не документальными снимками описанных объектов.

## Возможности

- Фильтры объектов по городам.
- Карточки с историей зданий.
- Добавление и удаление объектов из личного маршрута.
- Сохранение выбора в браузере (если доступен localStorage).
- Скачивание маршрута текстовым файлом.
- Адаптивная вёрстка.

## Файлы

- `index.html`, `style.css`, `app.js` — исходники для редактирования и статического хостинга.
- `beton.html` — тот же сайт в одном файле для удобного открытия.

Можно разместить содержимое репозитория на любом статическом хостинге. Для GitHub Pages выберите в Settings → Pages публикацию из ветки main, папка / (root).

Синтаксис JavaScript и основные операции фильтрации и коллекции проверены. Визуальная проверка в браузере не проводилась из-за недоступности предпросмотра среды.
